paginaverto

A pure-Rust PDF reader running entirely in your browser — no upload, no server. Your file never leaves this page.

It reads PDFs that carry a text layer: born-digital books and searchable scans. A scan without a text layer needs character recognition, which the library has and this page does not yet.
